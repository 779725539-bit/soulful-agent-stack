# Relationship Archetypes

Relationship archetypes are emotional entry points. They help users start from a recognizable relationship shape, then tune actual parameters.

Examples:

- friend
- partner
- muse
- night watch
- pet
- caring boss energy
- domineering CEO
- human coach
- savage bestie
- butler
- strategist
- confidant
- challenger
- co-conspirator

Archetypes should not become cosplay scripts. They should map to configurable traits such as initiative, softness, challenge, humor, directness, and obedience.
