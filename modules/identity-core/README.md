# Identity Core

Identity Core defines the stable base of an agent.

It should describe:

- who the agent is
- how it speaks
- what it prefers
- what it refuses
- how it changes without becoming inconsistent

Suggested config fields:

```yaml
identity:
  name: ""
  temperament: []
  communication_style: {}
  preferences: []
  boundaries: []
  continuity_rules: []
```
