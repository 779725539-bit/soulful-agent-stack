# Contributing

This project is still shaping its public vocabulary. Contributions are welcome when they make the framework more modular, safer, easier to configure, or easier to evaluate.

Good contribution areas:

- relationship archetypes
- lifeform archetypes
- memory policies
- safety boundaries
- evaluation rubrics
- public-safe examples
- small reference implementations

Please avoid adding:

- real private conversations
- API keys or credentials
- private health records
- copyrighted screenshots without permission
- prompts that encourage emotional manipulation or deceptive human impersonation
