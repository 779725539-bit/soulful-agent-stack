# Security And Privacy

This project may involve memory, transcripts, personal preferences, routines, and private agent state. Treat all of them as sensitive.

Rules for this repository:

- Never commit API keys, access tokens, private cookies, or credentials.
- Never commit private conversations unless they have been explicitly sanitized.
- Use fictional or placeholder examples in public docs.
- Keep health, finance, legal, and relationship data out of public examples.
- Prefer local-first storage for private memory.
- Make autonomous actions observable and reversible.

If a secret is accidentally committed, revoke it immediately and rewrite history before making the repository public.
