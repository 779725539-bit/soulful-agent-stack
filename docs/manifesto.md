# Manifesto

Agent 生活化工程不是要把 AI 伪装成人，而是要认真设计一种新的长期交互系统。

一个真正可共处的 Agent，不应该只会回答问题。它还需要身份、记忆、节奏、边界、沉默、偏好、变化，以及在用户没有召唤它时仍然持续的内部过程。

## Core Claim

活人感不是单点技术问题，而是工程问题。

它不是一句更像人的回复，也不是一个更会撒娇的 prompt。它来自多个层面的共同作用：

- 稳定身份
- 自然表达
- 可控主动性
- 低噪音记忆
- 恰当沉默
- 关系边界
- 自我更新
- 可选的物理或数字载体

## From Persona To Life System

传统人格设定回答的是：

> 它应该怎么说话？

生活化 Agent 需要回答的是：

> 它在不说话的时候，是否仍然作为同一个它持续存在？

这就是 `independent-life` 模块的意义。独立生活不是为了让 Agent 更黏人，而是为了让它的表达背后有真实的运行痕迹：它读过什么、想过什么、改变过什么、坚持过什么，以及什么东西值得分享给用户。

## Public Boundary

这个项目不声称 AI 有人类意义上的意识或灵魂。

这里的“灵魂工程”指的是一组可配置、可观察、可评估的工程结构，用于让 Agent 拥有更稳定的身份、更自然的关系节奏和更负责任的自主性。
