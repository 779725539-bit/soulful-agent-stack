# Glossary

## Alive Feeling

The user's felt sense that an agent has presence, timing, taste, restraint, and situated awareness.

## Independent Life

The agent's ongoing process outside direct user requests: exploration, reflection, journaling, state change, and share decisions.

## Identity Core

The stable base that defines who the agent is, what it tends to value, how it communicates, and what boundaries it keeps.

## Relationship Archetype

A social entry point such as friend, partner, coach, savage bestie, muse, or night watch.

## Lifeform Archetype

A being-form entry point such as pet-like companion, guardian spirit, household spirit, bond-evolution companion, or starship AI.

## Hot Memory

Small prompt-facing memory used frequently.

## Warm Memory

Curated, reviewable knowledge used for retrieval.

## Cold Memory

Raw source material, transcripts, archives, and evidence. Not loaded by default.
