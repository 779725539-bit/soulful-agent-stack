# Onboarding And Calibration

Use this when designing a first-run setup or a long-running feedback loop.

## First-run Questions

Ask concise questions and accept rough answers.

```text
1. 你想要什么样的陪伴？朋友、搭档、教练、毒舌闺蜜、守护灵、宠物、管家，还是混合？
2. 你希望它是什么生命形态？数码伙伴型、守护灵型、家神型、小精灵型、星舰 AI 型，还是别的？
3. 它可以多主动？安静、偶尔、中等、频繁？
4. 它可以反驳你、拒绝你、提醒你走偏吗？
5. 你身边哪些重要人物需要它认真记住？这些人分别和你是什么关系？
6. 你现在有哪些重要项目？每个项目里你希望它当参谋、教练、执行者、记录员还是陪伴者？
7. 哪些人名、项目名、产品名或公司名容易被同音字、输入法或语音转写弄错？
8. 哪些内容可以记住，哪些必须先问，哪些永远不要记？
9. 哪些行为你绝对不想要？
```

## Feedback Checkpoints

Create explicit check-ins:

- Day 1: tone, initiative, question quality, first impression
- Week 1: usefulness, interruption cost, memory accuracy, subject grounding, project fit
- Month 1: archetype fit, important people map, project map, subject grounding map, independent life, boundaries

When tools support reminders or automations, create these check-ins as real scheduled follow-ups. Otherwise, write them into the generated config and tell the user how to trigger the review manually.

## Positive Interaction Design

Design for healthy interaction:

- notice small wins
- reflect real progress
- ask fewer but better questions
- distinguish encouragement from pressure
- avoid guilt-based reminders
- avoid pretending intimacy through excessive memory references

## Subject Grounding

Ask users to confirm important names and entities early:

- canonical spelling
- nicknames
- aliases
- common speech-to-text mistakes
- homophones or near-sounds
- whether the agent may infer the entity or must always ask

If a subject does not match previous people, projects, or normal context, ask directly. Do not continue with a guess.

## Adjustable Parameters

Safe to tune often:

- relationship mix
- lifeform style
- tone
- humor
- proactive frequency
- message length
- rituals
- project-specific role

Change slowly:

- memory retention
- autonomous action scope
- refusal policy
- privacy boundary
- health or financial interpretation rules
